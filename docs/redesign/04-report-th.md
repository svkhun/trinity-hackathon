## ทิศทางที่เลือก

พิจารณา **โต๊ะตรวจต้นฉบับ**, **ตู้ทะเบียนแหล่งข่าว** และ **คู่มือภาคสนาม** แบบทะเบียนเริ่มที่ผู้เผยแพร่ ซึ่งโพสต์กำหนดเองอาจไม่ระบุ ส่วนคู่มือบังคับลำดับการอ่านมากเกินไปสำหรับผู้ที่มีโพสต์พร้อมตรวจ แบบต้นฉบับรองรับทั้งสองกรณีและเชื่อมข้อความกับข้อสังเกตได้ทันที [รายละเอียดสามแนวทางและ 12 ไอเดีย](02-brainstorm.md)

ตามคำขอเปลี่ยนฟอนต์ เลือก **Bai Jamjuree 600** สำหรับหัวเรื่องและคำอ้าง กับ **Sarabun 400/600** สำหรับเนื้อหาและ controls ทั้งสองชุดเสิร์ฟจากเครื่องพร้อมใบอนุญาต เก็บเฉพาะ WOFF2 ของไทยและ Latin และ preload ฟอนต์ไทยหลักสองไฟล์ Browser ยืนยันทั้ง computed family และสถานะ loaded [Design system](03-design-system.md) · [ผลตรวจฟอนต์](evidence/after/workflow.json)

## ตรวจรูปแบบซ้ำและ swap test

**Slop score 72 → 12/100** เป็นคะแนนบรรณาธิการตาม rubric เดิมด้านละ 20 คะแนน หลังปรับให้ภาพที่ขาดข้อมูล 0, โครงซ้ำ 5, หัวเรื่องที่สลับแบรนด์ได้ 3, ป้ายตกแต่ง 3 และ motion/สไตล์สำเร็จรูป 1 หน้ากราฟยังใช้หัว section และ controls ซ้ำเพื่อให้อ่านค่าข้ามหน้าได้ ค้นซอร์ส UI ซ้ำแล้วไม่พบ Terrain, Showcase, gradient, icon-tile, mini-bars, SIGNAL TOPOGRAPHY หรือ AnimatePresence จากหน้าก่อนปรับ [เกณฑ์และสิบจุดเดิม](01-audit.md) · [หน้าแรกใหม่](evidence/after/overview-1440.png) · [หน้าสัญญาณ](evidence/after/ai-analysis.png)

การสลับชื่อแบรนด์เพียงอย่างเดียวยังคงเหลือคำในโพสต์ไทย ชื่อกรณีจริงของเดโม ปุ่มเปิดเหตุผลที่ตรงคำ และจำนวนข้อสังเกตจากรายงาน หากย้ายภาพหน้านี้ไปใส่เว็บการเงินทั่วไป ผู้ใช้จะคาดหวังความสามารถตรวจถ้อยคำเหล่านี้ด้วย ผลนี้เป็นการตรวจเชิงบรรณาธิการ [ภาพ Fact Check](evidence/after/fact-check.png)

## ผลตรวจและข้อจำกัด

- Production build และ strict TypeScript ผ่าน Domain tests ผ่าน 4/4 ข้อ ครอบคลุมข้อสังเกตที่มาจากข้อความจริง การเว้นข้อสรุปเมื่อไม่มีหลักฐาน ความทำซ้ำได้ของ simulation และเงินต้นในตลาดที่ผลตอบแทนเป็นศูนย์ [Domain tests](../../tests/domain.test.ts)
- Playwright ตรวจทั้งห้า hash routes ที่ 390, 768 และ 1440px รวม 15 กรณี ไม่พบ horizontal overflow หรือ uncaught page error ทดสอบ keyboard skip, dialog/Escape, การคืน focus, disclosure, validation, custom post, clipboard, source switch และ slider/reset สำเร็จ [ผลทดสอบ](evidence/after/workflow.json)
- ตรวจ reduced motion ได้ transition 0s และ active animations 0 ในหน้าที่ทดสอบ การสแกน axe ตามกฎ WCAG A/AA ในห้าหน้าบน 390 และ 1440px ไม่พบ violation ทั้งสิบกรณี ผลนี้ครอบคลุมการตรวจอัตโนมัติและ flow ที่ระบุ การใช้งานร่วมกับ screen reader จริงและ Safari/iOS ยังต้องทดสอบ [ผล accessibility](evidence/after/workflow.json)
- โปรเจกต์เดิมไม่มี lint script จึงใช้ Biome จากโฟลเดอร์ QA ภายนอก ตรวจ 18 ไฟล์ใน app, components, lib และ tests ได้ 0 errors, 12 warnings และ 22 informational diagnostics ส่วนใหญ่เกี่ยวกับรูปแบบ CSS และการเขียนโค้ด ไม่มี placeholder รอข้อมูลจริงในงานออกแบบนี้ ข้อความ โปรไฟล์ และหลักฐานตัวอย่างยังเป็นข้อมูลสมมติ

## ลำดับถัดไป

1. **ผลสูง / แรงน้อย** ให้ผู้ใช้ไทยลองตรวจโพสต์ครั้งแรกโดยไม่อธิบายล่วงหน้า จับเวลาถึงการส่งตรวจและถามว่าคะแนนหมายถึงอะไร
2. **ผลสูง / แรงน้อย** ทดสอบเข้า–ออกแผ่นข้อสังเกตด้วย VoiceOver ภาษาไทยบน iPhone เพื่อฟังลำดับการอ่านและการประกาศผล
3. **ผลสูง / แรงกลาง** ให้ผู้ใช้เทียบกรณี MINT กับโพสต์ที่ไม่มีเอกสาร แล้วตรวจว่าจำแนก “ขัดกับหลักฐาน” กับ “ยังพิสูจน์ไม่ได้” ได้หรือไม่
4. **ผลกลาง / แรงน้อย** วัด Lighthouse ซ้ำหลายรอบบนเครื่องเดียวกันและใช้ค่ามัธยฐาน ก่อนตัดสินใจปรับ font loading เพิ่ม
5. **ผลกลาง / แรงกลาง** ทดลองให้ผู้อ่านอธิบายกราฟ RiskLab จากเปอร์เซ็นไทล์ที่ 5 ด้วยคำของตัวเอง แล้วปรับคำกำกับจุดที่ทำให้เข้าใจคลาดเคลื่อน
