# โต๊ะตรวจต้นฉบับ

## วัสดุและตัวอักษร

พื้นกระดาษ #F8F6ED หมึกหลัก #242720 สีรอง #696B5D (5.02:1) หมึกแดงสำหรับการกระทำ #A12F20 พื้นบันทึกคะแนนเป็นหมึกเข้ม ตัวอักษรกลับสี #FBF8EE ปากกาเน้นคำเป็นเหลืองอ่อน และเส้นใต้แดง ผู้ใช้ยังอ่านสถานะจากข้อความได้เมื่อปิดสี

ตามคำขอเปลี่ยนฟอนต์ ใช้ Bai Jamjuree 600 ในหัวเรื่องและคำอ้าง ส่วน Sarabun 400/600 ใช้ในเนื้อหา ฟอร์ม และปุ่ม ทั้งสองตระกูลโหลดจากเครื่องผ่าน WOFF2 ที่แบ่ง unicode-range สำหรับไทยและ Latin หัวเรื่อง fluid 36–68px หัวหมวด 22–30px เนื้อหา 15–18px คำกำกับ 12–14px ตัวเลขใช้ tabular nums กริดใช้ 4, 8, 12, 16, 24, 32, 48, 64px; radius 0 และ 4px ใช้เส้นคั่นแทนเงา ยกเงาเฉพาะแผ่นคำอ้างและ dialog

## ลำดับการอ่านและ primary action

| View | ลำดับ | การกระทำหลัก |
|---|---|---|
| Overview | หัวเรื่องและคำจากรายงาน → ต้นฉบับที่จะตรวจ → บันทึกคะแนนล่าสุด → ดัชนีรายงาน | ตรวจโพสต์นี้ |
| Fact Check | ฟอร์มกับผลล่าสุด → quote ขีดคำ → ข้อสังเกต / เอกสาร → ไปอ่านสัญญาณ | ส่งตรวจเมื่อแก้โพสต์ จากนั้นอ่านข้อสังเกตของผลล่าสุด |
| AI Analysis | ตัวชี้วัด → รูปแบบภาษาและกฎที่ใช้ → ข้อจำกัด | ตรวจแหล่งที่มา |
| Sources | เลือกโปรไฟล์ → ที่มา → จำนวนการอ้างอิง → timeline | เปิด RiskLab |
| RiskLab | ปรับสมมติฐาน → เทียบเงินต้นกับค่ามัธยฐาน → ดูหางซ้ายและแนวทางอื่น | ปรับจำนวนเงินหรือแนวทาง ผลเปลี่ยนทันที |

บนมือถือเรียงแบบคอลัมน์เดียว ย่อส่วนบทนำและคงเมนูด้านล่างพร้อมชื่อชัดเจน ขยายเป็นหัวเว็บแนวนอนที่ desktop; quote อยู่ขวา ฟอร์มใช้สองในสามของพื้นที่ ส่วนหลักฐานต่อท้ายเป็นรายการคั่นเส้น เพื่อลดการอ่านกล่องซ้อนกล่อง

## Controls และเสียงของข้อความ

- Button หลักใช้หมึกแดง hover เข้มขึ้น active มีเส้นขอบ focus-visible 3px มีพื้นที่สัมผัสขั้นต่ำ 44×44px
- Link ใช้เส้นใต้หรือหัวลูกศร คำที่ยกจากโพสต์เปิดข้อสังเกตนั้นได้ Native select ระบุ “เลือกกรณีศึกษา” และมีตัวเลือกสำหรับโพสต์เอง
- Textarea มี label, counter และ aria-invalid ผูกข้อความผิดพลาดกับฟิลด์ disabled และ loading บอกสถานะด้วยคำ “กำลังเทียบถ้อยคำ…” ระหว่างประมวลผล
- Disclosure ใช้ native details/summary เพื่อเปิดด้วย Enter หรือ Space แสดงสถานะหลักฐานและคำอธิบายติดกับคำเดิม
- Nav ระบุหน้าปัจจุบันด้วย aria-current และเส้นใต้; กด Escape เพื่อออกจากคู่มือได้
- Motion ใช้เฉพาะการเปลี่ยนสี 140ms ease-out หลีกเลี่ยงการเลื่อนหรือ fade ทั้งหน้า ลด motion ของกราฟและ UI เมื่อระบบร้องขอ
- เลี่ยงคำเชิงรับรอง เช่น “พิสูจน์แล้ว” เขียน “คะแนนจากกฎจำลอง” และ “ยังไม่มีหลักฐานต้นทางสำหรับข้อความนี้” ตามข้อมูลที่มี
