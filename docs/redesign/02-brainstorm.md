# สามแนวทางก่อนเลือก

**บุคลิก** ช่างสังเกต ตรงไปตรงมา สุขุม ผู้อ่านควรรู้สึกว่าตนเองเปิดดูที่มาของข้อสังเกตได้ จุดต่างคือการย้อนจากคะแนนไปหาคำไทยในโพสต์และเอกสารสมมติที่รองรับเฉพาะข้อ หลีกเลี่ยงกราฟที่ไม่มีข้อมูล ภาษาที่รับรองความจริง และป้ายอังกฤษซ้ำหัวไทย

แรงบันดาลใจจากนอกเว็บ: โต๊ะพิสูจน์อักษรให้วิธีขีดใต้คำและเขียนหมายเหตุข้างขอบ กระดาษทำบัญชีให้วิธีเรียงจำนวนกับหน่วยในแนวเดียวกัน ป้ายในหอจดหมายเหตุให้วิธีระบุว่าข้อความมาจากเอกสารใดโดยไม่กลบตัวเอกสาร

| ทางเลือก | โครงและตัวอักษร | สีและ contrast ของตัวอักษรปกติ | ปฏิสัมพันธ์ / ความเสี่ยง / effort |
|---|---|---|---|
| **โต๊ะตรวจต้นฉบับ** | หัวกระดาษแนวนอน ชื่อเรื่องไทยขนาดใหญ่คู่แผ่น quote ฟอร์มและบันทึกคะแนนอยู่คนละคอลัมน์ ใช้ Noto Serif Thai กับ Georgia สำหรับบทอ่านและ Noto Sans Thai สำหรับช่องกรอก | กระดาษ #F8F6ED กับหมึก #242720 13.99:1 สีดินสอแดง #A12F20 บนกระดาษ 6.59:1 | เปิดคำที่ขีดเส้นเพื่ออ่านเหตุผลจากรายงานจริง ความเสี่ยงคือธีมกระดาษกลบ disclosure; effort กลาง |
| **ตู้ทะเบียนแหล่งข่าว** | แบ่งจอ master/detail เริ่มจากรายการผู้เผยแพร่ ด้านขวาเป็นทะเบียนเอกสาร ใช้ IBM Plex Mono สำหรับรหัสและ Noto Sans Thai สำหรับคำอธิบาย | ตู้เขียวเข้ม #102825 กับข้อความ #EEF8F4 14.32:1 ไฮไลต์ทะเบียน #A1CFBA 8.98:1 | เลื่อนเลือกทะเบียนแล้วเปิด provenance และ timeline ความเสี่ยงคือโพสต์กำหนดเองไม่มีชื่อผู้เขียน จึงเริ่มต้นยาก; effort สูง |
| **คู่มือภาคสนาม** | แนวตั้งแบบพับแผนที่ เริ่มทีละคำถามแล้วเปิดช่วงถัดไป ใช้ Barlow Condensed เป็นหัวบทอังกฤษและ Noto Sans Thai เป็นคำแนะนำ | พื้นขาว #F7FAFC กับน้ำเงิน #102D55 13.11:1 แถบเหลือง #FEE39A กับน้ำเงิน 10.90:1 | ใช้แป้นลูกศรเทียบตัวอย่างตามดัชนี ความเสี่ยงคือขั้นตอนบังคับทำให้ผู้ใช้ที่มีโพสต์พร้อมอยู่แล้วต้องผ่านหลายหน้า; effort กลาง |

เลือก **โต๊ะตรวจต้นฉบับ** เพราะตัวเอกสารคือสิ่งเดียวที่มีอยู่ทั้งกรณีตัวอย่างและโพสต์กำหนดเอง ระบบมีข้อมูลพอที่จะขีดคำและเชื่อมไปยังคำอธิบายได้ทันที ทะเบียนเหมาะกับผู้ที่รู้ชื่อแหล่งข่าวอยู่แล้ว ส่วนคู่มือมีประโยชน์สำหรับบทเรียนตามลำดับมากกว่าการตรวจโพสต์ครั้งเดียว

## ไอเดียเรียงตาม impact ต่อ effort

| ลำดับ | รายละเอียด | impact / effort |
|---|---|---|
| 1 | ยกคำจากโพสต์จริงใน report มาทำตัวอย่างขีดเส้น เปิดไปยังข้อสังเกตที่ตรงคำ | สูง / กลาง |
| 2 | ตั้ง CTA ไทย “ตรวจโพสต์นี้” และใช้ปุ่มหลักเพียงปุ่มเดียวในฟอร์ม | สูง / ต่ำ |
| 3 | ใส่ชื่อกรณีในบันทึกคะแนนเพื่อแยก draft จากผลล่าสุด | สูง / ต่ำ |
| 4 | ย้ายตัวเลือกกรณีเข้า select ที่ใช้แป้นพิมพ์และจอเล็กได้ | สูง / ต่ำ |
| 5 | อ่านยอดคะแนนคู่กับความหมายและหน่วยในพื้นหมึกเดียว | สูง / ต่ำ |
| 6 | ให้ focus ไปถึงผลใหม่หลังส่ง และกลับไปช่องกรอกเมื่อ input ไม่ผ่าน | สูง / กลาง |
| 7 | ทำรายการทางเข้าต่อด้วยจำนวนข้อสังเกตหรือชื่อแหล่งจาก report | กลาง / ต่ำ |
| 8 | ให้แท็บปัจจุบันมีเส้นหมึกและ aria-current | กลาง / ต่ำ |
| 9 | เก็บเครื่องหมายผ่านที่ปุ่มคัดลอกเมื่อ clipboard สำเร็จผ่าน toast เดิม | กลาง / ต่ำ |
| 10 | แทนภาพ loading ด้วยข้อความว่ากำลังเทียบถ้อยคำกับกฎ | กลาง / ต่ำ |
| 11 | ใช้ตัวเลข tabular กับข้อมูลจำลองและสรุปบาทเพื่อเทียบข้ามแถว | กลาง / ต่ำ |
| 12 | เพิ่มโหมดพิมพ์รายงานแบบแผ่นเดียว | ต่ำ / กลาง พักไว้เพราะยังไม่มี flow พิมพ์ |
